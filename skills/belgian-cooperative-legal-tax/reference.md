# Belgian terms and institutions

Lookup table for the `belgian-cooperative-legal-tax` skill. Write the everyday words first and
the official term next.

| Everyday words | Official term (FR / NL where useful) |
| --- | --- |
| Private limited company | SRL (FR) / BV (NL); old name SPRL/BVBA |
| Cooperative | SC (FR) / CV (NL); old name SCRL/CVBA |
| Public limited company | SA (FR) / NV (NL) |
| Company law code | Code of Companies and Associations, CSA (FR) / WVV (NL) |
| Company rulebook | Articles of association (statutes) |
| Company register | BCE (FR) / KBO (NL) |
| Official Gazette | MB (FR) / BS (NL) |
| Directors | administrateurs (FR) / bestuurders (NL) |
| First right of existing owners to buy new shares | Pre-emption right |
| Value-added tax | TVA (FR) / BTW (NL) |
| EU VAT-number check | VIES (VAT Information Exchange System) |
| Company income tax | ISOC (FR) / VenB (NL) |
| Personal income tax | IPP (FR) / PB (NL) |
| Tax taken from wages | précompte professionnel (FR) / bedrijfsvoorheffing, BV (NL) |
| Payroll tax filing system | BELcotax |
| Tax authority | FPS Finance: SPF Finances (FR) / FOD Financiën (NL) |
| Economy ministry, market surveillance | SPF Economie (FR) / FOD Economie (NL) |
| Economic Law Code | CDE (FR) / WER (NL) |
| Data protection authority | APD (FR) / GBA (NL) |
| Customer accounts for VAT instead of seller | Reverse charge |
| Sale of goods between EU countries | Intra-community supply |
| EU statistics on goods moving between EU countries | Intrastat |
| Listing of supplies to EU business customers | EC sales list |
| Non-cash benefit | Benefit in kind / avantage de toute nature |
| Non-cash payment | Consideration in kind |
| Customs goods code | Harmonized System (HS) code |
| International delivery terms | Incoterms |
| EU crypto-asset rules | Markets in Crypto-Assets Regulation (MiCA) |
| Belgian financial markets regulator | FSMA |
| EU privacy law | GDPR |
| Data protection impact assessment | DPIA |
| Data protection officer | DPO |
| Standard contractual clauses for data transfers | SCCs |
| Goods with civilian and military use | Dual-use goods |

Rates, thresholds and dates change. Always check them against the official source.
